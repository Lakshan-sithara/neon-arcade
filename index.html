HOW TO ADD NEW GAMES TO NEONARCADE

You can add unlimited new games to this website in two easy ways: using the visual Admin Panel (no coding required) or adding a function directly in the code.

1

Method 1: Using the Admin Panel (Instant)

  1. Click on "Admin Panel" in the top navigation bar.
  2. Enter your Game Title, pick a Category (Action, Shooter, Puzzle, etc.), and choose an Emoji icon.
  3. Select Game Source Type:
    • External HTML5 Embed URL: Paste the URL of any web-hosted HTML5 game (e.g., from itch.io embed, GitHub Pages, or your own server).
    • Custom HTML5 / JS Code: Paste a self-contained HTML/Canvas snippet (or click "+ Load Sample Mini-Game Code" to test it right away!).
  4. Click "Publish Game to Lobby". Your game immediately appears in the Arcade Lobby for all registered users!
2

Method 2: Adding a Built-In Canvas Game in Code

All 10 default games use our unified inputState object so keyboard keys (Arrows/WASD/Space) and mobile touch buttons work automatically: 

// 1. Add metadata to DEFAULT_GAMES array:
{
  id: 'my_new_game',
  title: 'Cyber Racer',
  category: 'Action',
  icon: '🏎️',
  type: 'builtin',
  desc: 'Use Left/Right to steer!'
}

// 2. Read universal cross-device controls in your loop:
if (inputState.left) player.x -= 5;
if (inputState.right) player.x += 5;
if (inputState.action) fireLaser();
